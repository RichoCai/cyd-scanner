One micro-USB port = Single USB. USB-C and micro-USB = Dual USB.

This browser can't flash over USB. Open this page in desktop Chrome or Edge. Flashing needs HTTPS. Open the GitHub Pages link, not the file.
  • Select your CYD model from the dropdown
  • Connect the device with a USB data cable
  • Click CONNECT, pick the port, then INSTALL
💡Needs Chrome or Edge on a computer (WebSerial). Close any other app that's using the serial port, like Arduino IDE or a serial monitor. Stuck on “Connecting…”? Hold BOOT, tap RST, then let go.
