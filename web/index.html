One micro-USB port = Single USB. USB-C and micro-USB = Dual USB.

This browser can't flash over USB. Use desktop Chrome or Edge. Flashing needs HTTPS — open the GitHub Pages link, not the file.
  • Pick Single or Dual USB
  • Plug the CYD in with a USB data cable
  • Hit Connect, choose the port, Install
▲Needs Chrome or Edge on a computer. Close anything else using the serial port. Stuck on “Connecting…”? Hold BOOT, tap RST, release.

The interface

Touch the screen — tap a tile to open an app, drag to scroll, tap “‹” to go back.
